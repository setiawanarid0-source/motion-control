# H3 identity reference localization

YuNet locates one confident face on the current uploaded photo using the CPU.
The reported rectangle selects original pixels for an additional native H3
reference; no detector working image is uploaded or written over the photo.

Model: [OpenCV Zoo YuNet 2023mar](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet).
